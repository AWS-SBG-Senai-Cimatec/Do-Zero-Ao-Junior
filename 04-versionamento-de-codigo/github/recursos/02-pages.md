# GitHub Pages

O GitHub Pages é um serviço de hospedagem de sites estáticos diretamente a partir de um repositório do GitHub. Ele pode publicar páginas feitas com HTML, CSS e JavaScript, sem precisar configurar um servidor próprio.

## Para que serve

O Pages pode ser usado para publicar:

- Portfólios e páginas pessoais;
- Documentações de projetos;
- Sites de apresentação;
- Páginas de projetos acadêmicos.

## Publicação básica

1. Acesse o repositório no GitHub.
2. Abra **Settings**.
3. No menu lateral, clique em **Pages**.
4. Em **Build and deployment**, escolha a opção de publicação por uma branch.
5. Selecione a branch desejada e a pasta dos arquivos: `/ (root)` ou `/docs`.
6. Clique em **Save**.

O GitHub publicará o site e mostrará o endereço na própria página **Settings → Pages**. A publicação pode levar alguns minutos.

> Para publicar na pasta `/docs`, os arquivos do site precisam estar dentro dessa pasta. Para publicar pela raiz, eles devem estar na raiz do repositório.

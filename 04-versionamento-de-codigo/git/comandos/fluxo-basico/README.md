# 🚀 Tópico 1: Fluxo Básico (Comandos Fundamentais de Entrada)

>💡 **A Analogia Central:** Imagine que você é um fotógrafo profissional documentando a construção de um edifício. Você não tira apenas uma foto do prédio pronto; você registra cada etapa importante para ter um histórico completo.
>
>Para isso, primeiro você abre o estúdio e prepara o equipamento ([git init](./01-git-init.md) ou [git clone](./02-git-clone.md)). Conforme trabalha, olha no visor para ver o que mudou ([git status](./03-git-status.md)). Quando gosta do resultado de algumas fotos, separa-as na mesa de seleção ([staging area](./04-git-add.md)). Por fim, cola essas fotos no álbum oficial e escreve uma legenda descrevendo aquele momento ([git commit](./05-git-commit.md)). Esse ciclo de **preparar, selecionar e salvar** é a base do Git.

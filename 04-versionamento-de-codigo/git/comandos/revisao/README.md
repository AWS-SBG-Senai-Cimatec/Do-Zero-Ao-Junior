# 🔍 Tópico 2: Revisão (Inspeção e Auditoria de Alterações)

>💡 **A Analogia Central:** Imagine que é um auditor de documentos num escritório. Antes de aprovar a publicação de um livro, precisa olhar para as edições que sua equipe fez, comparar a versão atual com a versão anterior e inspecionar exatamente quem fez cada modificação.
>
>No Git, esse trabalho de auditoria é feito pelos comandos de revisão:
>* O [git log](./01-git-log.md) permite folhear o histórico de [commits](../fluxo-basico/05-git-commit.md).
>* O [git diff](./02-git-diff.md) compara linha por linha o que mudou entre o código atual, a [staging area](../fluxo-basico/04-git-add.md) e outras [branches](../ramificacao/README.md).
>* O [git show](./03-git-show.md) examina em detalhe as alterações de um [commit](../fluxo-basico/05-git-commit.md) específico.

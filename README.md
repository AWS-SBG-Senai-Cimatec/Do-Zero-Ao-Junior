# Do-Zero-Ao-Junior
A Trilha do Zero Ao Júnior é um RoadMap desenvolvido pelo time de Conteúdo e Serviços do AWS SBG onde o objetivo central é guiar o estudante do absoluto zero até um verdadeiro desenvolvedor Júnior. Este repositório centraliza todo material desenvolvido pelo time buscando acrescentar a comunidade nessa jornada.
